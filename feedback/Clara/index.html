技術亮點、報告與履歷

工作包技術亮點

菜單管理：用 Spring Security 角色規則與員工 JWT 過濾器，把後台菜單 API 限定給店長；顧客端只看得到「品項上架、分類也啟用」的菜，停用分類同時停止加入購物車與送單；分類的改名、排序、停用、刪除用資料列鎖排隊，兩位店長同時操作也不會出錯。出菜看板：點餐單的狀態一律由品項推導，勾選、整單完成、取消、報廢走同一套邏輯；出餐進度在交易提交後用 WebSocket 推給同桌每位客人；補上退菜紀錄、久候警示與深色大字看板。

報告建議

先用修正前的版本示範「沒登入也能刪菜單」，再展示修正後回 401、櫃檯帳號回 403。接著開著客人的菜單，店長在後台停用一個分類，客人畫面立刻少掉那一類，購物車裡的那道菜也送不出去。出菜看板：左邊開廚房看板、右邊開客人手機，廚師一勾，客人畫面馬上變「已出餐」；全部勾完卡片淡出；報廢一道菜，帳單自動扣掉。

履歷建議

可寫：「負責餐廳系統菜單管理：以 Spring Security 角色規則修正後台菜單 API 可被匿名呼叫的漏洞；實作分類排序、停用與防誤刪，並以資料列鎖讓停用分類與顧客送單正確排隊。」以及：「負責廚房出菜看板（KDS）：將點餐單狀態改為由品項推導，以固定鎖順序處理多名廚師同時操作，並以 WebSocket 在交易提交後把出餐進度推送給同桌顧客。」
