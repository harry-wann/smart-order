技術亮點、報告與履歷

用到的技術與設計模式

全隊共用的技術

  • 後端：Java 21、Spring Boot 4.1（Spring MVC REST API）、Spring Data JPA／Hibernate 7、MySQL 5.7、Lombok、Maven、統一錯誤格式（ApiException 加 @RestControllerAdvice）
  • 前端：React 19、React Router 8、Vite 8、Tailwind CSS 4、TanStack Query 5（伺服器資料快取）、axios、JavaScript／TypeScript 混用
  • 工具：Git 分支與 merge、oxlint（程式碼檢查）

這個工作包特有的

  • Spring Security 加 JWT（jjwt）：員工 StaffJwtProvider／StaffJwtFilter、會員與同桌點餐 JwtToken；員工密碼用 BCrypt 雜湊（SecurityConfig.java）
  • 金鑰管理：環境變數 CUSTOMER_JWT_SECRET、啟動時檢查（fail fast），token 加 typ 類型標記
  • Spring WebSocket／STOMP 訂閱授權（ChannelInterceptor，WebSocketConfig.java）；前端 @stomp/stompjs 推播 hook
  • 時區：HikariCP connectionInitSql（SET time_zone）、JVM 預設時區 Asia/Taipei（SmartOrderDataSourceConfig.java、SmartOrderApplication.java）
  • @Scheduled 排程、手動觸發 API 與 Clock 注入的業務時鐘（ReservationScheduler.java、ReservationConfig.java）
  • 原生 SQL 條件式 UPDATE（@Modifying）與 JPA 欄位 insertable/updatable=false（ReservationRepository.java、ReservationEntity.java）
  • Bean Validation（CreateReservationRequest、StaffLoginRequest）
  • AWS S3 SDK 接 Cloudflare R2 的共用圖片上傳（ImageUploadService.java、R2StorageConfiguration.java）
  • 前端共用連線層：axios 實例（createApiClient.ts）與 TanStack Query 設定（queryClient.ts）；CSS flex 與 Tailwind min-w-0（DashboardLayout.tsx）
  • 後端由 Kotlin 整理為純 Java（commit 081e34c）

設計模式

  • 分層架構（Controller–Service–Repository）：ReservationController、ReservationService、ReservationRepository
  • DTO（Data Transfer Object，資料傳輸物件）：reservation/dto 的 request／response
  • 悲觀鎖（SELECT ... FOR UPDATE）加時間區間重疊檢查：建立訂位時鎖住候選桌（ReservationService）
  • 樂觀並發控制與冪等：提醒用條件式 UPDATE 搶資格、看影響列數，跑幾次結果都一樣（ReservationRepository、ReservationJobService）
  • 及早失敗（fail fast）：伺服器不是只聽本機卻還用開發預設金鑰，或金鑰太短，就拒絕啟動（JwtToken）
  • token 類型區分：typ 標記讓會員、同桌、員工 token 不能互相冒用
  • 時鐘注入（Clock）：統一向它問時間，時區一致、方便測試
  • 模擬簡訊：提醒只寫 log、手機號碼遮罩，不真的發送
