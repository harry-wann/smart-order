後端從 Kotlin 整理成純 Java

Kotlin 和 Java 都能開發跑在 Java 虛擬機器上的後端。團隊統一用 Java，新手比較容易閱讀與交接。檔案數量只是變更範圍的描述，不能拿來推論功能增加或減少。

重構後

驗證

這次重構碰到的技術

  • Java 21 與 Maven：後端統一用 Java 寫，用 Maven 打包確認可建置。

名詞表

專有名詞

Kotlin／Java
兩種都能在 Java 虛擬機器上執行的程式語言；.kt 和 .java 分別是它們的檔案副檔名。
重構
整理程式內部結構或寫法，目標是不改變對外行為；仍要用檢查證據確認。
單元測試
針對一小段程式行為寫的自動檢查；只確認測試程式可編譯，不等於執行並通過。
Commit（版本提交）
記錄一組程式變更的版本歷史項目，可用識別碼對照修改內容。
