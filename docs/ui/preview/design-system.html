5　圖片佔位　★ 新增規範

設計稿與 HTML 草稿裡不准出現沒有說明的灰色方塊。 每個要放圖的位置都要當場寫清楚三件事：放哪一種圖、尺寸比例、建議搜尋關鍵字。 實作的人照著標註去 Unsplash / Pexels 搜就好，不用回頭問。

另外：一律挑亞洲／台式的照片，同畫面內色溫要一致——這是中高價位跟路邊店的差別所在。
