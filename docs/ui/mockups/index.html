看稿前先知道這五件事
  1. 三態示範只做在 C-04 和 S-02，其餘只有正常態。
  2. 標「進階」的 8 張有空才做：A1 C-15、A2 C-17、A3 S-09、A4 S-12、 A5 C-09～C-11、A6 C-20。其餘 35 張是基礎。 A7 人氣推薦沒有獨立畫面，是 C-04 裡標「進階 A7」的那一塊。
  3. 每個圖片佔位都寫了三行：放什麼圖、尺寸比例、搜尋關鍵字， 另外帶 data-layer="IMG／肉盤／1-1" 供 Figma 圖層命名。
  4. 店家端管理畫面不放照片，只有 S-05 的品項縮圖例外。
  5. 畫框外的標題列與說明卡只給這裡預覽，figma_prep.py 打包時會拿掉； Figma 上的說明卡來自 13-畫框註解.md。
