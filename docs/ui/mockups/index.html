  1. 三態示範只做在 C-04 和 S-02，其餘只有正常態。
  2. 每個圖片佔位都寫了三行：放什麼圖、尺寸比例、搜尋關鍵字， 另外帶 data-layer="IMG／肉盤／1-1" 供 Figma 圖層命名。

  4. 畫框外的標題列與說明卡是預覽用的，匯入 Figma 後刪掉那兩層就好。
