空資料　插圖＋一句話＋一個行動
購物車還是空的
挑一樣喜歡的加進來，這桌的人都看得到。
錯誤　中文訊息＋重試，不給客人看錯誤碼
菜單讀不到
網路好像不太穩。再試一次通常就好了，還是不行請找服務生。
鎖定　按下結帳後整桌不能再加點
這桌已經送出結帳，不能再加點了。
還想吃的話請按服務鈴，請服務生取消結帳。
同時內容整個壓淡、分類頁籤停用、購物車列消失
完成　勾勾描邊 0.6 秒後停住
只用在送出成功、付款完成、訂位完成這三處
