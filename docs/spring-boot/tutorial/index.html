一次只多一個觀念，不用先背名詞

若已學過 Servlet 與 Tomcat，可以對照舊經驗；還沒學過也能先讀 HTTP 請求與回應、Java 與 JDK。教材從第 2 單元開始；每個主題各有一頁，長範例可以展開。「選讀」第一次可以跳過。

每頁先交代已知的觀念與這次的任務，再看程式改哪裡、結果差在哪裡。看到新的專有名詞，會在對應內容中解釋用途與英文全名。

第三單元分成三步：03 先把物件傳進建構子；03A 換資料來源、比較輸出；03B 才讓 Spring 接手組裝，認識容器與 Bean。若你還感受不到差別，先停在 03A，不要急著背後面的註解。

前段「概念片段」不用拼成同一個專案；03A 另附獨立 Java 小練習。第 10 單元會使用 repository 的 backend 專案，依 10A～10D 逐層閱讀與驗收。

版本固定：以 Spring Boot 4 教學；有差異才補充 Boot 3。Spring Tools 5 是開發工具，不是 Boot 5。最後一頁整理 Boot 4 的實用新增能力。

  1. 10 · 實際應用：Northwind 商品 RESTful API
  2. 10A · 實作一：商品實體與資料合約
  3. 10B · 實作二：Service 與交易邊界
  4. 10C · 實作三：清單、單筆與寫入端點

第 10 單元的程式碼已放在 backend/。依序對照每一層的責任，最後照 10D 的命令驗收；第一次啟動先看 後端環境建置。

API 是 Application Programming Interface（應用程式介面）；REST 是 Representational State Transfer（表述性狀態轉移）。Hibernate 是物件與資料表映射工具，HQL 是 Hibernate Query Language（Hibernate 查詢語言）。首頁的名稱是路線預告，詳細觀念依單元順序解釋。
