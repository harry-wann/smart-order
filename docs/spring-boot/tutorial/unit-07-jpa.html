01 · JPA、Hibernate、Spring Data JPA

名稱全名與白話解釋
JPAJava Persistence API（Java 持久化 API），一套 Java 對應資料庫的標準規格。
HibernateORM（Object-Relational Mapping，物件關聯映射）框架，也是 JPA 的常見實作，會依 Entity 產生 SQL。
Spring Data JPASpring 提供的資料存取工具，讓你用 Repository 方法操作 JPA，減少 JDBC 樣板程式。

可以先記成：Spring Data JPA Repository → JPA EntityManager → Hibernate → JDBC → MySQL。JDBC 是 Java Database Connectivity（Java 資料庫連線 API）。

如果你剛接觸 SQL，先讀 關聯式資料庫與 SQL。既有的 ORM 與 JPA 短篇用火鍋店品項做概念例子；本課改用 Northwind 的實際表名，觀念相同。

02 · 對應 Northwind

目前專案的 Product 對應 MySQL 的 Products，欄位名稱明確寫在 @Column，所以不依賴自動命名猜測。

@Entity 表示可被 JPA 管理；@Table 指定資料表；@Id 指定主鍵。金額用 BigDecimal，不要用 double 做金額運算。

上面省略了 import、建構子、getter、setter 與其他欄位，因此不能直接覆蓋完整的 Product.java。MySQL 的 ProductID 由資料庫產生，完整檔案另有 @GeneratedValue(strategy = IDENTITY)。若使用本課附的最小 SQL，也要先匯入資料表才可呼叫 Repository。

03 · 基本 Repository

Spring Data 會提供 findById、findAll、save、delete。API 的基本 CRUD（Create、Read、Update、Delete，新增、讀取、更新、刪除）就是使用這些方法。

JpaRepository<Product, Integer> 的第一個型別是要操作的 Entity，第二個是主鍵 ProductID 在 Java 裡的型別。這個介面沒有手寫實作類別，Spring Data 會在啟動時提供實作。
