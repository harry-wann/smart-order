# 技術總表

> 這個專題會用到 50 項技術。**你不需要一次學完。**
> 每一項都有一頁 3～5 分鐘的說明，用最白話的方式講清楚「它是什麼、為什麼要它、我們拿它做什麼」。
> 每頁最後都有中文優先的學習資源，照著看就好。

## 怎麼用這份總表

1. **第 0 週**：全員把「必修」那八頁看完（大約 40 分鐘）
2. **每週開始前**：看一下你這週的模組頁，它會列出你這週需要哪幾項技術，把那幾頁先讀掉
3. **卡住的時候**：回來查。每頁都有「常見錯誤訊息對照」

## 難度標準

| 星等 | 意思 |
|---|---|
| ★☆☆☆☆ | 看一遍就會，照範例改就能用 |
| ★★☆☆☆ | 要理解一個新概念，但概念本身不難 |
| ★★★☆☆ | 要串起好幾個東西才會動 |
| ★★★★☆ | 有併發、交易或演算法要想清楚，容易寫錯而且不會報錯 |
| ★★★★★ | 要自己做架構決定 |

## 依工作項目的必讀清單

> **工作分配還沒決定**（我們預計以「功能切分」的方式分工——一個人負責一個功能的前後端，而不是切前端組／後端組）。
> 等八大模組的規格都定稿後再分配。在那之前，先照「你要做哪一類工作」來讀。

| **建立技術地基**（骨架、共用層、環境、部署） | 05、11、13～19、23、29、49、50 |
| **任何後端功能** | 12～19、22、25、26、27 |
| **任何前端畫面** | 30～40 |

| **即時同步相關**（M2、M3、M4、M5） | 41、42 |
| **定時任務相關**（M2、M5、M7、M8） | 43 |
