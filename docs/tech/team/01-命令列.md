# 命令列基本操作

**難度** ★☆☆☆☆　**用在哪些模組** 全員（環境建置）　**哪幾週** 第 0 週

## 一句話

命令列就是**用打字的方式叫電腦做事**，不用滑鼠點。

## 想像一下

平常你要開一個資料夾，是用滑鼠點兩下。命令列就是改成打 `cd 資料夾名字`。

聽起來比較麻煩，為什麼要用？因為**有些事情用滑鼠做不到，或是做起來很痛苦**。

- 「把這 200 個檔案的副檔名全部改掉」——滑鼠要點 200 次，命令列一行搞定
- 「啟動我的後端伺服器」——根本沒有一個按鈕可以按
- 「看看我改了哪些檔案」——Git 的功能大多只有命令列才完整

你不需要變成高手。**這個專題你只會用到大概 10 個指令。**

## 你只需要會這幾個

| 指令 | 意思 | 例子 |
|---|---|---|
| `pwd` | 我現在在哪個資料夾 | `pwd` |
| `ls` | 列出這個資料夾有什麼 | `ls` |
| `cd` | 走進某個資料夾 | `cd backend` |
| `cd ..` | 退回上一層 | `cd ..` |
| `mkdir` | 開一個新資料夾 | `mkdir docs` |
| `↑` 方向鍵 | 叫回上一次打的指令 | — |
| `Tab` 鍵 | 自動補完檔名 | 打 `cd back` 按 Tab |
| `Ctrl + C` | 停止正在跑的東西 | — |
| `clear` | 把畫面清乾淨 | `clear` |

**最重要的兩個是 `Tab` 和 `↑`。** 幾乎沒有人會把整串路徑打完，大家都是打幾個字按 Tab。

## 在我們的專案裡

你每天大概會打這些：

```bash
cd ~/projects/ispan/smart_order   # 走進專案資料夾
git pull                          # 把大家最新的程式碼抓下來
cd frontend                       # 走進前端資料夾
npm run dev                       # 啟動前端
```

後端的人則是在 IntelliJ 裡按播放鍵，或是：

```bash
cd backend
./mvnw spring-boot:run            # 啟動後端
```

## 15 分鐘動手小練習

打開終端機（Mac 是「終端機 Terminal」，Windows 建議用 Git Bash），完成這五件事：

1. 用 `pwd` 看看你現在在哪
2. 用 `cd ~/Desktop` 走到桌面
3. 用 `mkdir 練習` 開一個資料夾
4. 用 `cd 練習` 走進去（試試看打 `cd 練` 然後按 Tab）
5. 用 `pwd` 確認你真的進去了

做完這五步，這頁的目標就達成了。

## 你會遇到的坑

**① `command not found`**
你打的指令電腦不認識。通常是：打錯字，或是那個工具還沒裝。

**② 路徑裡有空格**
資料夾叫「my project」的話，要打 `cd "my project"`（加引號）或 `cd my\ project`。
→ **所以專案資料夾名字不要有空格和中文。**

**③ 不知道自己在哪個資料夾**
新手最常見的困惑。指令跑出奇怪的錯誤時，先打 `pwd` 和 `ls` 看看你到底站在哪。

**④ Windows 的路徑用反斜線**
Windows 是 `C:\Users\harry`，Mac/Linux 是 `/Users/harry`。教學文章多半是 Mac 寫的。
→ 建議 Windows 的人用 **Git Bash**，指令就跟 Mac 一樣了。

## 常見錯誤訊息對照

| 你會看到 | 中文意思 | 怎麼修 |
|---|---|---|
| `command not found` | 找不到這個指令 | 打錯字，或工具沒裝 |
| `No such file or directory` | 找不到這個檔案或資料夾 | 路徑打錯，先 `ls` 看看有什麼 |
| `Permission denied` | 沒有權限 | 通常是動到不該動的地方，先確認 `pwd` |
| `Address already in use` | 這個埠號已經有人用了 | 之前開的伺服器還沒關，`Ctrl + C` 關掉 |

## 術語對照表

| 白話 | 正式名稱 |
|---|---|
| 命令列、黑黑的視窗 | Terminal / CLI / Shell |
| 我現在在哪個資料夾 | 工作目錄（working directory） |
| 資料夾的完整地址 | 路徑（path） |
| `~` | 你的家目錄（home directory） |
