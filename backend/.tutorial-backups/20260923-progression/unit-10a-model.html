01 · 只映射本次要用的欄位

SQL Server 欄位Java 型別理由
ProductID · int identityInteger資料庫產生編號，新物件可先為 null
ProductName · nvarchar(40)String名稱最多 40
UnitPrice · moneyBigDecimal精確表示金額，最多四位小數
UnitsInStock · smallintShort符合資料庫型別；請求限制 0～32767
Discontinued · bitboolean是否停產
CategoryID · intCategory 關聯多項商品對一個分類

Northwind 的單價、庫存與分類欄位在表格中允許 null，因此讀取既有資料用可為 null 的型別；本課新寫入的 API 合約更嚴格，要求都有值。產品其他欄位仍留在資料庫，新建時由資料庫預設或 null 處理，更新則不碰它們。

03 · 請求 DTO：公開允許修改的欄位

DTO 是 Data Transfer Object（資料傳輸物件）。新增與 PUT 共用 ProductWrite，五個欄位都必填；PATCH 只接受 PricePatch。這個 API 不接受使用者自己指定 ProductID。
