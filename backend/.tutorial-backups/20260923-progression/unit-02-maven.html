Maven：從專案設定到可執行檔

你熟悉把 Web 專案放進 Tomcat。這一單元先看懂 Spring Boot 如何取得套件，再把專案打包起來。

01 · 先知道你正在管理什麼

Maven 是建置工具：下載依賴（Dependency，程式需要的外部套件）、編譯、測試與打包。POM 是 Project Object Model（專案物件模型），設定檔叫 pom.xml；XML 是 Extensible Markup Language（可延伸標記語言）。

編譯會把 Java 原始碼轉成位元組碼（Bytecode），再由 JVM（Java Virtual Machine，Java 虛擬機器）執行。JAR 是 Java Archive（Java 封裝檔）；WAR 是 Web Application Archive（Web 應用程式封裝檔）。

02 · 用一個依賴帶進 Web 能力

使用 Spring Boot parent（父設定）管理相容依賴。本課主線採 Boot 4.1.1 與 Java 21。

groupId 是組織；artifactId 是套件名稱。Starter 是預先組好的依賴組合，帶入 Spring MVC 與 Tomcat。受 Boot 管理的依賴不另填版本，完整 POM 在單元 10。

Boot 3 對照

Boot 3 使用 spring-boot-starter-web。Boot 4 改用 spring-boot-starter-webmvc；不要把舊版本依賴清單直接搬過來。

03 · 對照你熟悉的 Web 專案

位置放什麼
src/main/javaController、Service 與資料存取類別
src/main/resources設定檔與靜態資源
src/test/java自動化測試
target建置產物，不手動修改、不提交 Git

Spring Boot 的可執行 JAR 通常已帶入 Tomcat，不需要先把檔案搬到另一台 Tomcat 的 webapps。需要傳統 WAR 部署時仍然可以設定。

04 · 你親手執行時的順序

test 執行測試；package 會先經過編譯與測試，再打包；spring-boot:run 用於開發時啟動。這三行分別操作，不必一次全部執行。

mvnw 是 Maven Wrapper（Maven 包裝啟動器）：依專案指定版本取得 Maven，因此不必先全域安裝 Maven。第一次需要網路。若專案沒有 wrapper，但已安裝 Maven，可使用 mvn。這也修正先前把 Maven 全域安裝列為必須的說法。
