01 · 這次做到哪裡

REST 是 Representational State Transfer（表述性狀態轉移）；API 是 Application Programming Interface（應用程式介面）。我們建立商品的新增、查詢、更新與刪除，涵蓋 GET、POST、PUT、PATCH、DELETE，另外驗證 HEAD／OPTIONS。

小節完成後你會得到
10A · 實體與資料合約Product、Category、請求／回應 DTO、Repository
10B · 業務與交易分頁、查不到的處理、分類驗證、交易邊界
10C · HTTP 端點六個端點與一致的 400／404／409 回應
10D · 手動驗收每個方法的 curl、預期結果與錯誤案例

每次完成一頁再往下。全部 Java 類別放在 com.example.northwind，避免初學階段先被套件拆分干擾；正式專案可以再依功能拆分。每個 public 型別各存為同名檔案。

02 · VS Code 建立專案

  • 開啟命令面板，執行 Spring Initializr: Create a Maven Project。
  • 選 Java、Boot 4 的穩定版；本文可重現基準為 4.1.1，Java 21，JAR（Java Archive，Java 封裝檔）。
  • Group 填 com.example，Artifact 填 northwind-training，package 使用 com.example.northwind。
  • 選 Spring Web、Spring Data JPA、Validation、MS SQL Server Driver。確認產生的 Web starter 是 webmvc。
  • 選擇你自己的練習資料夾。若網站選單版本更新，以該版官方文件核對；先不要選 SNAPSHOT（開發快照）或 M／RC（里程碑／候選版）。

若產生的啟動類別叫 NorthwindTrainingApplication，可以保留；不用再複製第二個啟動類別。只要它位於 com.example.northwind 即可。以下提供完整 POM，供你逐項比對，不要求一次背起來。

03 · 資料庫前置條件

需要一個可連線的 SQL Server，以及已匯入 Microsoft 經典 Northwind 的練習副本。本文不假設你已安裝資料庫，也不自動匯入資料；如果尚未準備好，可先讀程式結構，連線驗收等資料庫就緒再做。

在你使用的 SQL 查詢工具先執行下列唯讀檢查。SQL 是 Structured Query Language（結構化查詢語言）。確認連到的是練習副本，而非其他人的資料庫。

04 · 設定資料庫連線

JDBC 是 Java Database Connectivity（Java 資料庫連線介面）。NORTHWIND_JDBC_URL、NORTHWIND_DB_USER、NORTHWIND_DB_PASSWORD 是你在啟動環境提供的三個變數，不是照抄的帳號密碼。

先修改網址與帳號再執行。read -s 會等待你輸入密碼並按 Enter，輸入不顯示在螢幕，也不用把真密碼寫進命令歷史。接著在同一終端機執行 ./mvnw spring-boot:run。若改用 VS Code 的執行按鈕，需確認它的啟動環境也拿得到這些變數。

上例 trustServerCertificate=true 僅用於自有練習環境的自簽憑證。正式連線要驗證憑證並依資料庫設定配置。若資料庫在另一台機器，主機與埠號要換成實際值。

ddl-auto=none 保留既有表格；open-in-view=false 要求在 Service 交易內完成資料轉換。PhysicalNamingStrategyStandardImpl 保留 ProductID 等指定名稱，避免命名策略轉成 product_id。拒絕未知 JSON 欄位可避免 PATCH 傳錯欄位卻以為成功。

這一輪只練資料 API，POM 尚未加入 Security，因此服務綁在 127.0.0.1。完成後再依單元 09 加入身分與權限；加入安全設定後，驗收的寫入請求也要帶憑證與 CSRF token。
