01 · 教材版本與三種產品名稱

本教材主線：Java 21、Spring Boot 4.1.1、Spring Framework 7、Hibernate 7。查核日期：2026-09-22。Boot 的相依管理負責協調各套件；不自行把不同主版本湊在一起。

產品做什麼版本不能互換
Spring Boot整合相依套件、自動設定與啟動本課用 4，補充 3
Spring Framework提供 IoC、MVC、交易等核心能力Boot 4 對應 Framework 7
Spring ToolsVS Code／Eclipse 等的開發工具Tools 5 不等於 Boot 5

官方索引尚未列出 Boot 5，所以沒有可據以撰寫的「Boot 5 比 4 多什麼」段落。Spring Tools 的版本不改變你 pom.xml 的 Boot 版本。

02 · 實用新增：內建 API 版本處理

API 是 Application Programming Interface（應用程式介面）。當商品回應欄位要改版，可用同一條路徑、不同版本標頭分派到不同方法。Framework 7 提供統一的解析與匹配機制，Boot 4 加入對應自動設定。

WebMvcConfigurer 與 ApiVersionConfigurer 來自 org.springframework.web.servlet.config.annotation。這個設定可能改變全站版本要求，請在獨立練習專案測試，不直接混入單元 10 的無版本端點。

Boot 3 對照

沒有 version 屬性時，可用 /api/v1/products 與 /api/v2/products 的獨立路徑，或 @GetMapping(headers="API-Version=1.0") 自行匹配。Boot 4 新增的是集中管理能力，不是 Boot 3 完全做不到版本化。

03 · 實用新增：外部 HTTP 服務分組管理

HTTP 是 Hypertext Transfer Protocol（超文字傳輸協定）。Northwind 若串接物流，可以把「查物流狀態」寫成 Java 介面。Boot 4 配合 Framework 7，增加 HTTP Service Client 的分組、註冊與自動設定，減少逐個建立代理的設定。

Client 是呼叫外部服務的端點；Proxy（代理）將介面方法轉成實際網路請求。@GetExchange 來自 org.springframework.web.service.annotation。

Boot 3 對照

Boot 3／Framework 6 已有 @HttpExchange 類型的介面客戶端；常需自行以 HttpServiceProxyFactory 組裝並宣告 Bean。Boot 4 的新價值是整組管理與自動設定，並非第一次能呼叫外部 API。

04 · 實用新增：核心重試與併發限制

Resilience（韌性）指外部服務短暫失敗時仍能控制影響。Framework 7 提供核心 @Retryable 與 @ConcurrencyLimit：前者重試，後者限制同時執行數量。Boot 4 可以在這一代核心框架上使用。

Northwind 查物流狀態遇到暫時網路錯誤，可考慮有限次重試；新增訂單與扣款不能盲目重試，要先有冪等設計。註解也需要啟用相應處理機制，不是只貼上名稱就會生效。

Boot 3 對照

Boot 3 常用獨立 Spring Retry 或其他工具處理。新核心註解在 org.springframework.resilience.annotation，和舊 Spring Retry 的 org.springframework.retry.annotation 不是同一個 import，設定與參數要依各自文件。

JPA／Servlet importsjakarta.persistence／jakarta.servletBoot 3 一樣是 jakarta.*
@MockitoBean可用3.4／3.5 可用；更早版本檢查相應 @MockBean 支援

Jackson 是 JSON（JavaScript Object Notation，JavaScript 物件表示法）的轉換工具。Boot 4 預設 Jackson 3，部分註解仍維持 com.fasterxml.jackson.annotation；不要只用全域取代遷移。

模組與測試 starter 拆得更細，能更明確帶入需要的測試支援，但不代表只改 parent 版本就完成升級。先確保測試通過，再改依賴、imports 與不相容設定。

06 · 哪些能力其實 Boot 3 就有？

  • IoC（Inversion of Control，控制反轉）與 DI（Dependency Injection，依賴注入）不是 Boot 4 新功能。
  • REST Controller、建構子注入、JPA、交易與 ProblemDetail 在 Boot 3 已可使用。
  • Java record 與 BigDecimal 是 Java 語言／標準函式庫能力，不是 Boot 4 發明。
  • 不要把「新版預設不同」誤認為「舊版做不到」；先確認是框架新增、整合改善還是套件更名。
