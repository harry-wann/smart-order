單元 05 · NORTHWIND LAB

先走通一個請求，再學三層分工

先用一筆已知的 Northwind 商品資料，把 Controller、Service、Repository 串起來。這頁不加入資料庫查詢或交易。

Spring Boot 4 主線有差異再看 Boot 37 個閱讀步驟

先備觀念：已知道 Spring 用建構子注入依賴，Controller 的方法可以處理 GET 請求。

讀完能做到：從 /demo/product 一路指出資料來源、組裝方式與 JSON 回應；看懂每個類別的工作。

01 · 先決定這次要回傳什麼

固定任務：GET /demo/product 回傳商品 1 的名稱 Chai。前一頁學過 JSON（JavaScript Object Notation，JavaScript 物件表示法），先把預期結果寫出來。

這頁的資料固定在程式裡，讓你專心追蹤請求。第 07 單元才把來源換成真正資料庫；第 10 單元再擴充新增、修改與錯誤處理。

02 · 先定義資料形狀，再使用它

DTO = Data Transfer Object（資料傳輸物件），用來表達「要傳出去哪些欄位」。本例的 ProductView 只需要 id 和 productName。Java 的 record 是簡潔資料型別，會自動產生建構子與讀取方法。

ProductView 是我們自己取的名稱，不是 Spring 內建型別。先認得它，再看後面方法為什麼都把 ProductView 寫在方法名稱前面：那是宣告回傳值的型別。

03 · Repository：提供資料

Repository（資料存取層）專注資料從哪裡取得。這裡先用一個普通類別提供固定資料；還沒有介接資料庫，也沒有任何自動查詢魔法。@Repository 是用來表達資料存取角色的 Spring 元件標記。

findExample 是我們自己寫的方法，回傳剛才定義的 ProductView。這次直接建立固定資料；之後學 JPA 時會改成資料庫實體與查詢。

04 · Service：安排應用要做的事

Service（服務層）負責應用流程與業務規則。這次只有讀一筆資料，所以它很短；往後像「分類是否存在、停產商品是否能下單」才會在這裡判斷。@Service 表達這個角色，也把類別登記為 Spring 元件。

這和 03A 的 ProductLabel 接收 ProductCatalog 是同一個原理，只是角色名稱不同。Service 使用資料來源，不在自己裡面建立 Repository。

05 · Controller：接住請求，回傳結果

Controller 的工作是把網路請求接到應用方法。本例只要收到 GET /demo/product，就呼叫 Service 的 getExample()。@RestController 會讓這個資料物件轉成 JSON 回應。

四個類別放在 Boot 啟動類別可掃描的同一套件或子套件。此處為了讀懂分工省略 package 宣告；實際建立專案時仍要與資料夾一致。這套短示例與第 10 單元是不同階段的替代版本，不要同時放入兩個 ProductController。

06 · 用兩條流程看懂注入與請求

何時發生什麼
啟動時Spring 找到 Repository，建立它；交給 Service；再把 Service 交給 Controller
有請求時Controller 呼叫 Service，Service 呼叫 Repository，Repository 回傳 ProductView
回應時ProductView 逐層回傳，框架轉成 JSON 送出

不要把「組裝順序」和「方法呼叫順序」混為一談。通常不是每次 GET 都重新 new 一組這些預設共用的元件；每次請求是在呼叫它們的方法。

07 · MVC 和三層架構，再放在一起比較

MVC = Model–View–Controller（模型、視圖、控制器）。Model 是顯示需要的資料，View 是畫面呈現，Controller 協調請求。你學過的 Servlet 與 JSP 就能用這個角度理解。

Controller／Service／Repository 是應用的責任分層，不是 MVC 三個字母的替代名稱。資料 API 回傳 JSON，沒有 JSP 畫面層，也仍然可以使用 Spring MVC 處理請求。

角色自己檢查責任的方法
Controller是否主要在處理路徑、輸入與回應？
Service是否主要在處理應用規則與流程？
Repository是否主要在處理資料取得與保存？
DTO是否只定義傳輸的資料形狀？

不需要。先改資料存取部分，必要時調整 Service；Controller 維持它的請求與回應責任。完整資料庫做法從第 07 單元開始。
